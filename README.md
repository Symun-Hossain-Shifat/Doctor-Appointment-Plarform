# 🩺 Doctor Appointment Booking Platform

A full-stack doctor appointment booking platform that allows patients to find doctors, schedule appointments, and manage bookings efficiently. The platform provides a seamless experience for patients while enabling doctors and administrators to manage appointments effectively.

## 📖 Project Overview

The Doctor Appointment Booking Platform is designed to simplify the healthcare appointment process. Patients can browse available doctors, view detailed profiles, and book appointments online. The system ensures secure authentication, appointment management, and a responsive user experience across all devices.

## ✨ Key Features

### 👨‍⚕️ Doctor Discovery
- Browse and search doctors by specialization.
- View detailed doctor profiles, qualifications, and experience.
- Filter doctors based on specialty and availability.

### 📅 Appointment Scheduling
- Book appointments with preferred doctors.
- View upcoming and past appointments.
- Manage appointment status efficiently.

### 🔐 Secure Authentication
- User registration and login.
- Protected routes for authenticated users.
- Role-based access control for Patients, Doctors, and Admins.

### 📱 Responsive User Experience
- Mobile-friendly and fully responsive design.
- Intuitive and user-friendly interface.

### ⚡ Real-Time Data Management
- Dynamic appointment updates.
- Efficient data fetching and state management.
- CRUD operations for doctors and appointments.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/doctor-appointment-booking.git
```

### Navigate to the Project Directory

```bash
cd doctor-appointment-booking
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file and add:

```env
NEXT_PUBLIC_API_URL=your_api_url
MONGODB_URI=your_mongodb_uri
BETTER_AUTH_SECRET=your_secret
BETTER_AUTH_URL=http://localhost:3000
```

### Run the Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
